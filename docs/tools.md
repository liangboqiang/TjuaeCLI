# 内置工具

智能体常规注册 10 个内置工具。LLM 会根据任务与工具策略自动选择并调用它们；启用
计划模式时还会注册 EnterPlanMode 和 ExitPlanMode，MCP 工具则在连接服务器后动态
加入，不计入这 10 个常规工具。

| 工具 | 功能 | 可并发 |
|------|------|--------|
| **Read** | 读取文件内容并附带行号 | 是 |
| **Write** | 写入文件，自动创建目录 | 否 |
| **Edit** | 精确替换字符串 | 否 |
| **ExecCommand** | 执行 shell 命令 | 否 |
| **Grep** | 通过 ripgrep 使用正则表达式搜索文件内容 | 是 |
| **Glob** | 按模式查找文件 | 是 |
| **ViewImage** | 从本地绝对路径加载图片并附加到下一轮模型输入 | 是 |
| **Skill** | 按名称加载技能内容、权限、钩子与上下文修改 | 否 |
| **Spawn** | 启动子智能体并行处理任务 | 否 |
| **ToolSearch** | 加载延迟工具的 schema | 是 |

---

## Read

读取文件内容并显示行号，行为类似 `cat -n`。

- 支持通过 `offset` 和 `limit` 参数读取文件片段。
- 自动检测二进制文件。
- 输出格式为带行号的文本。

## Write

以原子方式向文件写入内容。

- 先写入临时文件，再重命名，确保原子写入。
- 自动创建父目录。

## Edit

在文件中查找并替换精确字符串。

- 精确匹配 `old_string`，并替换为 `new_string`。
- 默认要求唯一匹配；存在多个匹配项时返回错误。
- 使用 `replace_all` 替换全部匹配项。

## ExecCommand

执行 shell 命令并返回结果。

- 默认超时 120 秒，最长 600 秒。
- 返回退出码、标准输出和标准错误。

## Grep

使用正则表达式搜索文件内容。

- 优先使用 `rg`（ripgrep），不可用时回退到 `grep -rn`。
- 支持 glob 过滤和忽略大小写搜索。
- 结果最多保留 250 行。

## Glob

查找符合 glob 模式的文件。

- 支持标准 glob 模式，例如 `**/*.rs`。
- 按修改时间排序，最新文件在前。
- 最多返回 100 个文件。

## ViewImage

从本地绝对路径读取受支持的图片，返回简短的文本结果，并把图片作为独立内容块附加
到下一轮模型输入。图片二进制不会进入文本工具结果；当前模型不支持图片输入时，
该工具不会向模型公开。

## Skill

按系统提示词中列出的准确名称调用技能，可选传入一段参数字符串。技能可以返回上下文
修改和动态钩子，因此按保守策略顺序执行，并受技能级 allow/deny 与自动批准设置约束。

## Spawn

参阅高级功能指南中的[子智能体](advanced.md#子智能体)。

## ToolSearch

加载延迟工具的完整 schema，使 LLM 能够调用它们。来自设置了
`deferred = true` 的 MCP 服务器的工具在注册时只有名称；只有当 LLM 调用
ToolSearch 后，参数 schema 才会加载。

- 按精确名称查询：`"select:Read,Edit,Grep"`。
- 关键字搜索：`"slack send"` 返回最匹配的结果。
- 默认最多返回 5 个结果。

## 工作原理

```text
用户输入 → 构建请求（系统提示词 + 历史记录 + 工具定义）
         → 流式接收 LLM API 响应
         → 实时向标准输出写出文本
         → 若 LLM 返回 tool_use，则确认、执行并回传结果
         → 循环，直到 LLM 停止调用工具
         → 输出最终答复并保存会话
```

- 支持并发的工具（Read、Grep、Glob、ViewImage、ToolSearch）会并行执行。
- 不支持并发的工具（Write、Edit、ExecCommand、Skill、Spawn）会顺序执行；Spawn
  在自身内部管理子智能体并发。
- 工具输出会自动截断，防止超出上下文窗口。
- 工具输出支持压缩，详见[输出压缩](advanced.md#输出压缩)。

## 工具描述

每个内置工具都带有详细描述和使用建议，并会注入系统提示词。这些描述帮助 LLM
选择合适的工具并正确使用，例如搜索内容时优先使用 Grep 而不是 ExecCommand，
修改文件时使用 Edit 而不是 Write。
